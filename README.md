# ☸️ Azure Kubernetes Service (AKS) with Terraform

A clean and standard Terraform configuration to provision an **Azure Kubernetes Service (AKS)** cluster with:
- Azure CNI network plugin
- System-assigned managed identity
- Virtual Machine Scale Set default node pool

## 🚀 Usage
`ash
terraform init
terraform plan
terraform apply
`
